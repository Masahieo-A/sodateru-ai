# 構成メモ（開発者向け）

- **GitHub**: `Masahieo-A/sodateru-ai`
- **Web**: Next.js 16 / React 19 / TypeScript / Tailwind CSS 4
- **Cloudflare互換層**: vinext
- **DB**: Cloudflare D1。スキーマは `migrations/`、実行時バインディング名は `DB`
- **認証**: Google OpenID Connect。`hd` と検証済みメールの両方で `tomidah.com` に限定
- **教員権限**: `TEACHER_ALLOWLIST` またはD1 `teacher_allowlist` の明示登録
- **AI**: Gemini API。入力サイズ制限、参加者所有権確認、再送用の冪等化をAPI側で実施
- **教材**: JSON Schema、実行時バリデータ、サンプルを `curriculum/` と `lib/curriculum/` に配置

Cloudflareに設定する値は `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`AUTH_SECRET`、`GEMINI_API_KEY`、`APP_URL`、`TEACHER_ALLOWLIST` です。秘密値はリポジトリへコミットしません。

`wrangler.jsonc` の `database_id` はD1作成後に実IDへ差し替えます。本番URLは当面 `sodateru-ai.<Cloudflareサブドメイン>.workers.dev` を使い、独自ドメインは後から追加できます。
